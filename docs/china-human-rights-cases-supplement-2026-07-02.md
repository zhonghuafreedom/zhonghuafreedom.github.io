# 中国因言获罪、人权抗争、民主抗议与跨境迫害个案增补稿（审核版）

更新时间：2026-07-02
用途：供 zhonghuafreedom.org 后续扩充“因言获罪”“维权律师”“公民记者”“白纸运动”“跨境镇压”“民族与宗教权利”“香港国安法”等专题使用。

## 使用说明与事实核查原则

1. 本稿只使用公开资料整理，不是完整政治犯数据库。中国人权案件数量远超本稿范围，本文优先列入国际关注度高、能够找到公开来源、适合做网站专题页的案例。
2. “罪名 / 指控”是中国或香港官方司法体系使用的说法，不代表本文认可这些指控。
3. 对官方判决文件不透明、信息来自家属、人权组织或媒体转述的个案，本文标注“据报道”“公开信息有限”或“需继续核验”。
4. 建议正式发布前逐条检查姓名、日期、刑期、羁押地点、释放状态、来源链接是否仍有效；对仍在中国境内或可能连累家人的当事人，避免暴露非公开联系方式、家庭地址、聊天记录或求助渠道。
5. 网站写作建议采用“证据型、资料型”语气：先写日期、地点、指控、判决、来源，再写人权意义和国际关注。

## 1. 刘晓波

- 分类：因言获罪 / 民主倡议
- 关键日期：2008-12-08 被拘押；2009-12-25 被判刑；2010-10-08 获诺贝尔和平奖；2017-07-13 羁押中病逝
- 官方罪名 / 指控：煽动颠覆国家政权
- 判决或目前状态：判刑 11 年；2017 年在服刑期间因肝癌去世
- 事件摘要：刘晓波是《零八宪章》主要起草人之一。官方将其参与起草民主改革文本、发表亲民主文章等作为定罪证据。其案件是“文字、联署、和平倡议”被国家安全罪名处理的标志性案例，也是国际上最受关注的中国良心犯案件之一。
- 写作与核查备注：事实公开度高，可作为网站“因言获罪”专题的核心案例。
- 主要来源：[Tom Lantos Human Rights Commission, Liu Xiaobo profile](https://humanrightscommission.house.gov/DFP/Countries/China/Liu-Xiaobo)

## 网站改写建议

1. 每个专题页顶部放一段“为什么重要”：说明该类案件侵犯了哪些权利，例如表达自由、结社自由、宗教自由、免于酷刑、正当程序、非遣返原则、新闻自由等。
2. 每个案例卡片固定格式：姓名 / 身份 / 日期 / 地点 / 罪名 / 刑期或状态 / 事件经过 / 国际反应 / 来源。
3. 不要把“据报道”写成“官方确认”。例如彭立发据报道被判 9 年，但官方未公开完整判决，必须保留限定语。
4. 对仍在押或家属仍在境内的人，避免使用未经公开授权的家庭细节。
5. 建议在每页底部加入“最后更新日期”和“资料来源”列表，方便本地 AI 或读者核查。
